Privacy Policy

Updated: 20 October 2026

Technical requests

The hosting provider receives request data such as IP address and browser information to serve pages. This guide has no account, booking, contact form or feedback email interface.

External services

Google Fonts and the embedded Google map may receive browser/IP information when loaded. The server requests weather and sea-level model data for the place coordinates from Open-Meteo; it does not request the visitor’s device location. Google Analytics loads only after analytics consent. Each provider has its own policy.

Browser choices

Use Cookie Settings to refuse or change analytics consent. Choices are stored when browser storage is available. A failure message explains the limits; refusal still takes effect immediately on the current page.
